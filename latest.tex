本文研究了 mixed Hodge modules 的 Dolbeault cohomology 的 generic vanishing 现象, 其中 Dolbeault complex 的 differential 被一个 one-form 修正. 作者证明了在 Higgs line bundles 的 Dolbeault moduli space 上, cohomology support loci 与非交换 Hodge 对应诱导的映射下 de Rham moduli space 上底层的 $\mathscr{D}$-modules 的 cohomology support loci 的像一致, 并将其应用于 abelian varieties 上 mixed Hodge modules 的 Fourier-Mukai transforms.

本文利用 algebraic $K$-theory 上的 motivic filtration 研究 normal affine surfaces 与 threefolds 上的 vector bundles. 作者通过 Chern classes 对临界秩的 vector bundles 给出分类, 并讨论了三fold 上给定 motivic Chern classes 的 rank $2$ bundles 的存在性.

\arxivwithtarget{2610.22758}{$R$-trivial Galois cohomology classes and cohomological $p$-dimension}{Charles De Clercq}\textbf{math.AG}.

本文研究域 \(F\) 上的 Galois cohomology class 的 \(R\)-triviality 与 cohomological \(p\)-dimension 之间的关系. 作者在 iterated Laurent series 域上构造例子, 说明当 cohomological \(p\)-dimension 为 \(n+1\) 时 \(H^n(F,V)\) 中存在非 \(R\)-trivial 的类, 从而说明相关上界是 sharp 的.

\arxivwithtarget{2610.23228}{Weighted configurations and the nonexistence of arithmetic ball quotient compactifications}{Ryunosuke Nakano, Hisato Matsukawa}\textbf{math.AG}, math.CV, math.NT.

本文证明了与十维复向量空间 \(V_{10}\) 上的 trivector \(\sigma\) 相关联的、非常一般的 Debarre--Voisin hyperkähler fourfold \(Y\subset\Gr(6,10)\) 满足 Beauville--Voisin conjecture. 具体而言, 作者证明 cycle class map 在由 divisor classes 与 tangent bundle 的 Chern classes 生成的 Chow ring 子代数上是单射. 这一结果为 hyperkähler 簇的 Chow ring 结构提供了新的证据, 并推进了 Beauville--Voisin conjecture 的研究.

本文研究了数域上光滑几何整的拟射影簇 $X$ 的对称幂的 Brauer-Manin 障碍. 作者证明了对称幂上的 Brauer-Manin 障碍与 $X$ 本身的障碍一致, 并由此得出对称幂无法为 $X$ 的零轮弱逼近提供新的上同调障碍. 关键工具包括 Brauer 群的 Dold-Thom 型结果以及 adel 点的精细下降公式.


\arxivwithtarget{2610.23457}{Smooth Limits of Stable Manifolds}{Mu-Lin Li}\textbf{math.AG}.

本文修正了 cyclic quantum dilogarithm operators 基本定义中的 $\boldsymbol{\mu}_N$-phase 问题. 作者扩展了 global coefficients 的概念以纳入构成 $\boldsymbol{\mu}_N$-cover 的额外 lifting data, 并指出 pentagon relation 一般会多出一个 $\boldsymbol{\mu}_N$-factor. 文章进一步证明 partially compactified cluster Poisson variety 的正则轨迹上的每一点都可提升为 strict extended global coefficient, 从而恢复原文结论.


\arxivwithtarget{2610.23592}{Locally Gorenstein algebras, a generalization of Gorenstein algebras}{Leonardo Alarcon, María Andrea Gatica, Marcelo Lanzilotta}\textbf{math.AC}, math.RT.

本文在 Artin algebra $\Lambda$ 上引入了 locally Gorenstein modules 的概念, 推广了 semi-Gorenstein projective modules 与 Gorenstein projective modules. 作者构造了子范畴 $\underline{\chi}_X$ 并证明了 syzygy functor 在其上的忠实性与完全性, 进而说明 Igusa-Todorov functions $\phi$ 与 $\psi$ 在该族上为零. 最后定义了 locally Gorenstein algebras 并证明其 finitistic dimension 与 $\phi$、$\psi$ dimensions 有限.
