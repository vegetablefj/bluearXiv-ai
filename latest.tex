本文研究了实现 Haagerup center 的三种 vertex operator algebra 构造之间的关系. 作者在 $E_6\oplus A_2$ 的公共 lattice basis 下显式给出了生成元, 并证明了 Riesen 与 Huang 的构造给出同构的 vertex operator algebra, 而该 algebra 与 Jiao 的构造在二阶 automorphism 下的 fixed point subalgebra 同构. 文中还给出了 unitary vertex operator algebra 的一个 rationality criterion 并应用于这些构造.


\arxivwithtarget{2611.04942}{An Ito-Michler type theorem and the prime class graph of weakly integral braided fusion categories}{Sebastian Burciu}\textbf{math.QA}, math.GR.
