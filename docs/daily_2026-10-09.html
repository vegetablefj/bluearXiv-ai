A Proof of Mongardi's Conjecture on Finite Symplectic Group Actions on Hyperkähler Manifolds of $K3^{[n]}$ Type ⭐ 精选
Jie Fu, Shihao Wang, Zhiwei Zheng
math.AG
本文证明了 Mongardi 猜想：若有限群以 symplectic automorphisms 忠实作用于 \(K3^{[n]}\) type 的 hyperkähler manifold (\(n\geq2\))，则其关联的 Leech coinvariant lattice \(S\) 满足严格不等式 \(\mathrm{rk}(S)+\ell(A_S)<24\)。核心想法是考察代表 \(S\) 的 discriminant classes 的向量的最小范数：numerical walls 的缺失给出某些类的下界，而 Leech lattice 的结构给出所有 discriminant classes 的上界，两者比较将证明归结为有限多个 \(n\) 的情形。作者进一步用 lattice arguments 结合 Höhn--Mason 关于 Leech lattice 的 fixed-point sublattices 的分类排除了剩余情形，从而完整证明了该猜想。这一结果与 Huybrechts 和 Mongardi 独立证明的逆命题一起，完整刻画了 \(K3^{[n]}\) type hyperkähler manifolds 上有限 symplectic group actions 的 Leech coinvariant lattice。
Hyperkähler SYZ conjecture ⭐ 精选
Philip Engel, Mirko Mauri
math.AG
本文证明了 hyperkähler SYZ conjecture: 对任意非平凡的 nef isotropic line bundle, 其某个正幂次的 sections 定义一个 Lagrangian fibration. 这一结果将 SYZ 猜想从物理与几何直觉提升为 hyperkähler geometry 中的严格定理, 对理解 hyperkähler manifolds 的 fibration structure 与 mirror symmetry 具有重要意义. 证明涉及对 nef isotropic line bundle 的 positivity 与 base locus 的精细分析, 并最终构造出 Lagrangian fibration. 该工作与 hyperkähler 及 K3 surface 的几何研究密切相关.
